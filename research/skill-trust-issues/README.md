# Skills Trust Issues Research Pack

Date: 2026-05-06

This folder contains research findings on trust risks in AI skills ecosystems:

- [01-prompt-injection.md](./01-prompt-injection.md)
- [02-tool-poisoning.md](./02-tool-poisoning.md)
- [03-malware-supply-chain.md](./03-malware-supply-chain.md)
- [04-community-signal-reddit-and-forums.md](./04-community-signal-reddit-and-forums.md)

## Top-line findings

1. Prompt injection is active and practical, especially indirect injection through untrusted external content.
2. Tool poisoning is a core agent risk when tool outputs are mixed into planning context without strict trust boundaries.
3. Malware and supply-chain compromise in skill/plugin ecosystems are confirmed by both advisories and field research.
4. Community reports on Reddit and forums align with official guidance, but anecdotal posts must be separated from confirmed incidents.
